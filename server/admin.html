🚚 服务器迁移

输入新服务器的 IP、SSH 端口和用户名（默认 root），选择密码或密钥登录，一键把本机 BigCat 全部内容（程序文件、数据库、主题、配置）原封不动迁移过去。目标服务器会自动安装 BigCat 并配置 systemd 开机自启。密码/密钥仅用于本次迁移，不会被保存。使用非 root 用户时，特权操作会自动通过 sudo -i 以 root 身份执行，该用户需具备免密 sudo 权限（如甲骨文云的 ubuntu）。迁移过程中本机可正常使用。
